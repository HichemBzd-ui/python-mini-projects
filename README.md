# Python Mini Projects

Small Python programs I wrote while learning the basics of the language.
Each file is a short, self-contained exercise focused on one concept.

## Projects

| File | What it does | Concepts practiced |
|------|--------------|--------------------|
| `calculator_program.py` | Simple calculator (+, -, *, /) | user input, `if / elif / else`, floats |
| `weight_converter_fr.py` | Converts a weight between kilograms and grams | input, conditions, arithmetic |
| `tableau_de_multiplication.py` | Prints the multiplication table of a number | `for` loops, `range()` |
| `hypotenuse.py` | Computes the hypotenuse of a right triangle | `math` module |
| `aire_triangle_rectangle_arabic.py` | Area of a right triangle (prompts in Arabic) | input, arithmetic |
| `fast_food_order.py` | Takes a small food order and prints a summary | input, f-strings |
| `meteo_condition.py` | Prints a message depending on the weather | booleans, chained comparisons |
| `entree_control_if_statements.py` | Examples of `if`, `elif` and `else` | conditions |
| `verifier_caractere.py` | Checks whether a character appears in a string | `in` operator, strings |
| `tableau_informations.py` | Displays user information as a small table | f-strings, formatting |
| `jeux_madlips.py` | Mad Libs word game | input, f-strings |

## How to run

```bash
python calculator_program.py
```

Any file can be run the same way with Python 3.
